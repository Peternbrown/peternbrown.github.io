GIS · Full-Stack Product Build — City of New York

Tree Block Pruning Manager

I led this project as both product owner and sole developer. I ran discovery directly with forestry stakeholders to define requirements, then designed and built the full application myself — from data pipeline to front end. It's now the system of record foresters use to run the tree block pruning program from the field.

Data moves from the field into the system through an FME Interoperability + SQL ETL workflow, with ArcGIS Pro used to build and manage the map layers. The front end runs on ArcGIS Online, using Experience Builder for the desktop app and Field Maps for crews working on-site.

Key Features Delivered

  • Upload and flag field data points for re-checking
  • Visualize contractor work areas across the pruning program
  • Batch-edit points to update status and attributes at scale
  • Query estimated work cost and other program variables
  • Filter and slice data by crew, block, status, and other fields

My Role

Product manager and sole developer — led stakeholder discovery to scope requirements, then owned design and delivery of the ETL, map layers, and front-end experience end to end.

Impact: Replaced an ad hoc, spreadsheet-driven process with a single system of record — giving foresters real-time visibility into work status, cost, and crew assignment.

Stack

FME Interoperability SQL ArcGIS Pro ArcGIS Online Experience Builder Field Maps

GIS · Python Automation — City of New York

Survey123 Image Pipeline

I identified a recurring operational drag: field teams collected photos through a Survey123 survey, but getting them off the platform meant going through every image one by one and saving it manually to a desktop — roughly three hours of repetitive work every week.

I scoped and built a Python automation using the arcpy package that downloads the images in bulk, renames and organizes them, and pulls the accompanying spreadsheet of GIS data tied to each photo — then uploads everything automatically to SharePoint for team-wide access, with zero manual steps.

Capabilities

  • Bulk-downloads images from a Survey123 survey
  • Renames and organizes files by a consistent naming convention
  • Exports the associated GIS attribute spreadsheet
  • Uploads the full set to SharePoint for team-wide access

Stack

ArcGIS Pro Python arcpy SharePoint
Impact: Eliminated ~3 hours of manual work per week — 150+ hours a year reclaimed for higher-value work, with zero risk of missed or mis-filed field photos.
